# Fintech Transaction Insights

## Dataset summary

The cleaned dataset contains:

- 199,033 transactions
- 5,000 customers
- 300 merchants

## Daily activity

The busiest transaction date was **2025-02-28**,
with **605 transactions** and a total
amount of **416,112.11**.

## Payment channels

The most frequently used payment channel was **UPI**,
with **99,727 transactions**.

The channel with the highest total transaction value was
**UPI**, with a total amount of
**67,213,379.19**.

## Merchant categories

The merchant category with the highest transaction value was
**grocery**, with a total amount of
**29,280,638.26**.

## Customer activity

The customer with the highest total transaction value was
**C00225**, with a total amount of
**194,171.39**.

## Transaction statuses

The most common transaction status was **success**,
with **185,292 transactions**.

## Fraud

There were **2,113 fraud-labelled transactions** and
**196,920 non-fraud transactions**.

The overall fraud rate was approximately **1.06%**.

## Conclusion

The ETL pipeline cleaned and combined customer, merchant, and transaction
data. It produced insights about daily activity, payment channels,
customers, merchant categories, transaction statuses, and
fraud-labelled transactions.

The data is synthetic, so these findings demonstrate an analysis workflow
rather than real-world banking behavior.
